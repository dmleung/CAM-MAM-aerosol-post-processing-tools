# CAM-MAM-aerosol-post-processing-tools
A repo for using Python or other languages to process CAM/MAM aerosol outputs and calculate PM2.5 (fine particulate matter below an aerodynamic diameter of 2.5 μm).
One needs at least the aerosol mass (e.g., so4_aX) and the dry number geometric diameter (dgnumX) for the calculation.
